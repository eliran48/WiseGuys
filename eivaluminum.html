אופן ההתקדמות: מודול א' - צ'אטבוט

הקמת מערך מענה ואוטומציה ב-WhatsApp Meta API

  1. שלב א': חתימה על הצעת המחיר

    אישור דיגיטלי בטופס מטה והנפקת דרישת תשלום/חשבונית התנעה.

  2. שלב ב': אפיון מפורט

    גיבוש תסריטי השיחה, הגדרת השאלות, הסגמנטציה וזמני החזרה המבוקשים.

  3. שלב ג': פיתוח והקמה

    בניית הלוגיקה, הגדרת המערכות ב-Meta WhatsApp API והכנת התבניות.

  4. שלב ד': הצגה, תיקונים, בדיקות וחיבורים

    סקירת הדגמה, דיוק הניסוחים, סנכרון ל-CRM / Google Sheets ובדיקות איכות (QA).

  5. שלב ה': יציאה לדרך והשקה! 🚀

    חיבור המערכת לערוצי הלידים הנכנסים והפעלת המענה האוטומטי בלייב.

אופן ההתקדמות: מודול ב' - קמפיינים

ניהול קמפיינים ממומנים ב-Meta & Google Ads

  1. שלב א': חתימה על הצעת המחיר

    אישור המסלול הנבחר והסדרת התשלום הראשון של הריטיינר החודשי.

  2. שלב ב': קבלת גישות לנכסים

    חיבור לחשבונות המודעות בפייסבוק, אינסטגרם וגוגל, פיקסלים ומערכות אנליטיקה.

  3. שלב ג': ניתוח, שיפור עמודי נחיתה והשקה

    ניתוח ביצועי עבר, ייעול עמודי הנחיתה (eivaluminum.nue.co.il), הקמת מודעות והשקה.

  4. שלב ד': מעקב צמוד ואופטימיזציה שוטפת 📈

    ניהול יומיומי, אופטימיזציית קהלים וקריאייטיב, ומעקב שוטף להורדת עלות לליד איכותי.

• תקציבי מדיה ופרסום: תקציב הפרסום (עד 20,000 ₪) מועבר ישירות מול פלטפורמות המדיה (פייסבוק, אינסטגרם, גוגל) באמצעות כרטיס האשראי של הלקוח.

• אחריות דיוור וחוק הספאם: על הלקוח/בעל העסק לוודא כי כלל הנמענים והמתעניינים שאליהם יישלחו המסרים והדיוורים הינם מאושרי דיוור בהתאם לחוק (חוק התקשורת / חוק הספאם). לא תהיה לספק כל אחריות משפטית או ניהולית בנוגע לחוקיות איסוף ושליחת המסרים.

• תנאי תשלום: מודול א' (צ'אטבוט) משולם במלואו בתחילת העבודה. מודול ב' (ניהול קמפיינים) משולם כריטיינר בתחילת כל חודש פעילות.
